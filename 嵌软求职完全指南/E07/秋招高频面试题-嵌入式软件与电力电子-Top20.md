## 一、嵌入式软件方向（Q1–Q11）

### Q1. `volatile` 关键字的作用？典型使用场景有哪些？
**（区分"C 程序员"和"嵌入式程序员"的最经典题，几乎必考）**

**标准答案：**
`volatile` 告诉编译器：该变量可能以编译器无法预知的方式被改变，因此**禁止对它做激进优化**。优化器每次用到该变量时，都必须重新从**内存**读取它的真实值，而不是使用此前缓存在 CPU 寄存器里的副本。

**三大典型场景：**
1. **硬件寄存器**：内存映射 I/O（如串口状态寄存器），其值随硬件状态随时变化。
2. **中断服务程序（ISR）与主程序共享的全局变量/标志位**：ISR 可能随时修改它。
3. **多线程/多任务共享变量**：防止编译器优化导致读到旧值。

**加分项 / 易翻车点：**
- `volatile` 解决的是**可见性与重排（编译器层面省略读取）**问题，**不等于原子操作，也不保证多核缓存一致性，更不是同步原语**。把 "volatile = 线程安全" 是最常见的翻车点。
- 可以 `const volatile` 并存：例如指向**只读硬件寄存器**的指针，`const` 表示"我的代码不会写它"，`volatile` 表示"它的值会被硬件改变，每次都要重读"。

### Q2. `const` 关键字？请辨析指针相关的几种写法
**标准答案（口诀：const 靠谁近，谁就不能改）：**
```c
const int a;        // a 是常量，不可改
int const a;        // 同上，与上一行等价
const int *p;       // p 指向的【值】不可改，p 本身可改指向
int * const p;      // p【指针本身/地址】不可改，所指的值可改
const int * const p;// 值和指针都不可改
```

**为什么要用 const：**
1. 向阅读代码的人传达语义（这个参数是只读的）；
2. 给编译器优化提供信息，可能生成更紧凑的代码；
3. 强制保护不希望被修改的数据，减少 bug，提高健壮性。

### Q3. 复杂指针/声明题（"右左法则"经典套题）
**标准答案：**
```c
int a;            // 整型数
int *a;           // 指向整型的指针
int **a;          // 指向"整型指针"的指针
int a[10];        // 10 个整型的数组
int *a[10];       // 数组，含 10 个"指向整型的指针"
int (*a)[10];     // 指针，指向"含 10 个整型的数组"
int (*a)(int);    // 函数指针：参数 int，返回 int
int (*a[10])(int);// 数组，含 10 个上述函数指针
```
**方法（右左法则）**：从标识符出发，先看右边（`[]`、`()`），再看左边（`*`），遇到括号则在括号内按同样规则展开。

### Q4. `static` 关键字的三种用途？
**标准答案：**
1. **修饰局部变量**：改变其**存储方式/生命周期**——只初始化一次，函数退出不销毁，保留上次的值（存在静态区，不在栈上）。
2. **修饰全局变量**：改变其**作用域**——只在本源文件可见（内部链接），避免命名冲突。
3. **修饰函数**：同样限制为**仅本文件可见**的内部函数。

**内存角度补充**：已初始化的 static → `.data` 段；未初始化的 static → `.bss` 段（启动时清零）。

---

### Q5. 内存分区？堆和栈的区别？
**标准答案 —— 一个 C 程序的内存布局：**
- **栈区（stack）**：局部变量、函数参数、返回地址；由系统自动分配释放；向**低地址**增长。
- **堆区（heap）**：`malloc`/`new` 动态申请；由程序员手动释放，忘记释放会**内存泄漏**；向**高地址**增长。
- **数据段**：`.data`（已初始化全局/静态变量）、`.bss`（未初始化，清零）。
- **常量区** `.rodata`：字符串常量等只读数据。
- **代码段** `.text`：函数的二进制指令。

**堆 vs 栈核心区别：**
| 维度 | 栈 | 堆 |
|---|---|---|
| 分配/释放 | 系统自动 | 程序员手动 |
| 速度 | 快 | 慢（需查空闲链表） |
| 大小 | 小（MB 级） | 大（受可用内存限制） |
| 增长方向 | 低地址 | 高地址 |
| 风险 | 栈溢出 | 内存泄漏/碎片 |

### Q6. `sizeof` 与 `strlen` 的区别？
**标准答案：**
- `sizeof` 是**运算符**，**编译期**求值，计算类型/变量占用的**总字节数**，对字符串**包含** `'\0'`。
- `strlen` 是**库函数**，**运行期**从首地址数到 `'\0'` 为止，**不包含** `'\0'`。

**两个坑：**
- `sizeof(指针)` 只取决于系统位数：32 位 = 4，64 位 = 8，与所指内容无关。
- **数组作为函数参数会退化为指针**，此时 `sizeof` 得到的是指针大小而非数组大小，所以数组长度必须在外部计算后传入。

---

### Q7. 大端与小端（字节序）？如何用代码判断？
**标准答案：**
- **大端（Big-Endian）**：高位字节存在低地址。
- **小端（Little-Endian）**：低位字节存在低地址（x86/大多数 ARM 默认）。

以 `int a = 0x12345678` 为例，大端在低地址依次存 `12 34 56 78`，小端则是 `78 56 34 12`。

**判断代码（union / 指针强转）：**
```c
int is_little_endian(void) {
    union { int i; char c; } u = { .i = 1 };
    return u.c == 1;          // 1 → 小端
}
// 或：
int x = 1;
return (*(char*)&x == 1);    // 1 → 小端
```

### Q8. 如何访问一个绝对内存地址 / 操作硬件寄存器？
**标准答案：** 把整型地址强制转换为指针即可（嵌入式特色题）。例如把地址 `0x67a9` 处的整型变量写为 `0xaa55`：
```c
int *ptr = (int *)0x67a9;
*ptr = 0xaa55;
```
**加分项**：实际操作寄存器时通常写成 `*(volatile uint32_t *)0x40021000 = value;`，必须加 `volatile`（见 Q1），位操作用 `|=`（置位）、`&= ~`（清位）。

### Q9. `typedef` 与 `#define` 的区别？野指针/内存泄漏？
**标准答案：**
- `#define` 是**预处理**的纯文本替换，不做类型检查；`typedef` 是**编译期**的类型别名，更安全。
  例如 `#define dPS struct s *` 后 `dPS p1, p2;` 会展开成 `struct s *p1, p2;`（p2 不是指针！），而 `typedef struct s* tPS; tPS p1, p2;` 两个都是指针。
- **野指针**：指向未知/已释放内存的指针。成因：① 未初始化（指针默认值随机）；② `free`/`delete` 后未置 `NULL`。**防范**：定义即初始化为 `NULL`，释放后立即置 `NULL`，使用前判空。
- **内存泄漏**：`malloc`/`new` 后未释放，且失去了指向它的指针。

### Q10. RTOS 基础：任务调度、信号量与互斥锁、可剥夺内核？
**标准答案：**
- **RTOS 定义**：能在**确定时间内**响应外部事件、任务执行时间可预测的操作系统。
- **调度算法**：优先级抢占式调度（保证关键任务及时执行，但低优先级可能饥饿）、时间片轮转（公平但实时性弱）。
- **可剥夺型内核**：高优先级任务可立即打断（抢占）正在运行的低优先级任务，响应快，是主流 RTOS（FreeRTOS）的做法。
- **信号量 vs 互斥锁（FreeRTOS）**：
  - **二值信号量**：常用于 ISR → 任务的**同步**（通知"事件发生了"）。
  - **计数信号量**：管理多个相同资源。
  - **互斥信号量（Mutex）**：用于**互斥**访问共享资源，且支持**优先级继承**，可缓解优先级反转。
- **关键工程经验（加分）**：**ISR 要短**——只做采样/搬运/置标志/发通知，复杂处理交给任务（如串口收到数据先丢进环形缓冲/队列，再由任务处理）。很多实时性问题不是 RTOS 不行，而是 ISR 干太多事。

### Q11. STM32 三大通信协议（UART / SPI / I2C）与 DMA 的区别？
**标准答案：**

| 协议 | 同/异步 | 线数 | 双工 | 速度 | 特点 |
|---|---|---|---|---|---|
| **UART** | 异步 | 2（TX/RX） | 全双工 | 较低 | 无时钟线，靠波特率+起止位同步；点对点 |
| **SPI** | 同步 | 4（MOSI/MISO/SCLK/CS） | 全双工 | 高 | 主从，CPOL/CPHA 决定 4 种模式；一主多从靠片选 |
| **I2C** | 同步 | 2（SDA/SCL） | 半双工 | 中 | 双线总线，开漏+上拉，靠地址寻址，支持多主仲裁 |

- **SPI 四种模式**：由 **CPOL（时钟空闲电平）** 和 **CPHA（采样边沿）** 组合决定。
- **I2C 三种信号**：起始（SCL 高时 SDA 下降）、停止（SCL 高时 SDA 上升）、应答 ACK；地址 = 7 位地址左移 1 位 + 读写位。**仲裁**遵循"线与 + 低电平优先"。
- **DMA**：外设/内存间**不经 CPU**直接搬运数据，传输完成产生中断通知 CPU，从而**解放 CPU**去做更重要的事；支持 内存↔内存、内存↔外设 三种方向。

## 二、电力电子方向（Q12–Q20）

### Q12. 三大基本 DC-DC 拓扑（BUCK / BOOST / BUCK-BOOST）的区别？
**标准答案（应届硬件/电源岗几乎必考）：**
- **BUCK（降压）**：Vo < Vin，极性相同。
- **BOOST（升压）**：Vo > Vin，极性相同。
- **BUCK-BOOST（升降压）**：Vo 可大可小，**极性相反**。

由这三种基本拓扑可派生出 Flyback（反激）、Forward（正激）、CUK、半桥、全桥等。
**"拓扑"的本质**：电感、电容、开关器件（MOS/二极管）三者的连接关系决定了电路功能。

---

### Q13. PWM 与占空比？三种拓扑的电压增益公式（CCM）？
**标准答案：**
- **PWM**：脉宽调制；周期 `Ts = Ton + Toff`，频率 `f = 1/Ts`，**占空比 `D = Ton/Ts`**。
- **连续导通模式（CCM）电压增益：**
  - BUCK：`Vo/Vin = D`
  - BOOST：`Vo/Vin = 1/(1-D)`
  - BUCK-BOOST：`Vo/Vin = -D/(1-D)`（负号代表极性反转）

**推导思路（加分）**：稳态时电感**伏秒平衡**（一个周期内电感电压积分为 0），由此即可推出上述关系。

---

### Q14. BUCK 电路工作原理？续流二极管的作用？
**标准答案：**
- **开关管 Q 导通**：输入经电感给负载供电，同时电感储能（电流上升）。
- **开关管 Q 关断**：电感电流不能突变，通过**续流二极管 D** 维持流向负载——D 的作用就是**提供续流回路**，故称续流二极管。
- **电感/电容口诀**：电感**阻碍电流变化**（通直阻交、通低频阻高频）→ 平滑电流；电容**阻碍电压变化**（通交阻直、通高频阻低频）→ 平滑电压、滤波。
- "不隔离"：输入输出在同一回路、无变压器隔离。

---

### Q15. 电源纹波是什么？如何测量与抑制？
**标准答案：**
- **定义/测量**：纹波反映输出电压的波动，测 **峰峰值 Vpp**。
- **示波器测量要点**：① 带宽限制设为 **20MHz** 滤除高频噪声；② **就近接地**，接地夹换成**接地弹簧/接地环**，减小环路引入的噪声。
- **抑制方法：**
  1. **提高开关频率**（频率越高纹波越小）；
  2. **加大电感和输出电容**（电流脉动 ∝ 1/L，纹波 ∝ 1/C）；
  3. **电容组合**：大容值铝电解（储能）并联**陶瓷电容**（低 ESR、抑制高频）；
  4. **二级 LC 滤波**：再加一级 LC 进一步衰减纹波。

---

### Q16. BUCK-BOOST 的典型应用场景？拓扑如何选型？
**标准答案：**
- **典型场景——宽输入电压**：如**汽车冷启动**时电池电压可能跌到 6V 甚至更低，又可能高于目标输出；用 Buck-Boost 可保证电池在 4V~12V 波动时仍稳定输出 5V。
- **选型依据**：输入/输出电压范围、效率要求、成本、EMI 限制、是否需要隔离等。
  - Vin 始终 > Vout → BUCK；Vin 始终 < Vout → BOOST；Vin 跨越 Vout → BUCK-BOOST / 四开关 Buck-Boost。

---

### Q17. 开关管与二极管如何选型？效率如何计算？
**标准答案：**
- **开关管**：一般选 **MOSFET**，关注 **Rds(on)（导通电阻）、Qg（栅极电荷）**、耐压裕量、开关速度、峰值电流。华为电源笔试明确：硬开关 MOS 初选主看 **Rdson 与 Qg**。
- **二极管耐压**：在 BOOST / Buck-Boost 中，二极管需承受 **(Vin + Vout)** 的电压，应在此基础上留裕量。
- **效率**：`η = Pout / Pin × 100%`；损耗主要来自**开关损耗 + 导通损耗 + 电感磁损 + 二极管压降损耗**。

---

### Q18. MOSFET 与 IGBT 的区别？如何选用？
**标准答案：**
- **结构/驱动**：都是电压驱动、栅极绝缘；MOSFET 是多子器件，IGBT 是 MOS+BJT 复合（带电导调制）。
- **关键差异 —— 关断拖尾电流**：IGBT 关断时有**拖尾电流（tail current）**，导致开关损耗大，且**拖尾电流随温度升高而增大**；MOSFET 没有这个问题，开关速度快。
- **导通压降**：大电流/高压下 IGBT 通态压降更有优势（饱和压降近似恒定），MOSFET 压降 ∝ Rds(on)×I。
- **选型经验**：**低压（≤600V）、高频** → MOSFET；**高压、大电流、中低频**（电机驱动、逆变器）→ IGBT。
- **体二极管坑（加分）**：硬开关应用中，MOSFET 体二极管反向恢复较慢，常成为限制开关频率的因素。

---

### Q19. SiC / GaN 宽禁带器件相比 Si 的优势？
**标准答案：**
- **更高开关频率 + 更低损耗** → 可减小磁性元件/电容体积，降低系统体积、重量和成本。
- **SiC MOSFET vs Si IGBT 关键优势**：SiC MOSFET **原理上无拖尾电流**，关断损耗极低（SiC+SBD 较 IGBT+FRD 关断损耗 Eoff 可降约 **88%**）；某 2kVA 逆变器把 IGBT 换成 SiC MOSFET，单器件损耗从 14.4W 降到 8.5W（约 **−41%**）。
- **导通电阻温度稳定性好**：温度升高时 SiC 的 Rds(on) 变化较小。
- **应用区分**：GaN 偏中低压高频（适配器、LLC、Class-D）；SiC 偏高压大功率（车载 OBC、主驱逆变、光伏）。
- **注意点**：高速开关需仔细调整外置栅极电阻 Rg，并注意驱动回路寄生电感、米勒导通、EMI。

### Q20. 死区时间与环路补偿？峰值电流模式的次谐波振荡？
**标准答案：**

**死区时间（Dead Time）：**
- 目的：防止桥臂上下管**直通短路（shoot-through）**，让一个管彻底关断后另一个再开。
- 权衡：死区**过大** → 输出波形畸变、THD 升高、占空比损失（电流过零附近误差）；**过小** → 直通风险。SiC/GaN 开关快，可设更小死区，但对驱动时序精度要求更高。

**环路补偿（Loop Compensation）：**
- 目的：保证闭环稳定与动态响应。关键指标：**穿越频率/带宽**（一般取 fsw/5 ~ fsw/10）、**相位裕度 ≥45°（推荐 60°）**、增益裕度。
- 补偿器类型：电压模式（LC 双极点）常用 **Type III**；电流模式（单极点）用 **Type II** 即可。
- **RHPZ（右半平面零点）**：Boost / Buck-Boost / Flyback 在 CCM 下存在右半平面零点，会限制带宽，需把穿越频率压低。

**次谐波振荡（华为笔试点）：**
- **峰值电流控制模式**下，当**占空比 D > 50%** 时会产生**次谐波振荡**，需加**斜坡补偿（slope compensation）**消除。

## 三、备考建议

1. **嵌入式**：吃透 **`volatile`/`const`、指针声明（右左法则）、内存管理（堆栈/野指针）** 三大块——这是面试官最爱层层追问的地方。后半段更看**工程化能力**（ISR 分层、故障定位、项目真实性），背题不如把"语言机制"和"硬件/并发场景"连起来。
2. **电力电子**：按 **拓扑原理 → 公式推导（伏秒平衡）→ 器件选型 → 纹波/EMC → 控制环路** 的主线系统准备。
3. **车规电源岗**：额外补充 **AEC-Q100 / ISO 16750、EMC 优化、冷启动/高温等极端工况、功能安全**。
4. 公式类（电压增益、效率、占空比、纹波）务必能**手推**，面试官常要求白板推导。
