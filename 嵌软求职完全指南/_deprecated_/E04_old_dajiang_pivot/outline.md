## 核心论点（一句话）

> 已经进了纯软大厂，为什么还要转嵌软？因为「短期信号」和「长期价值」不是一回事。

## 大框架（4-5 个内容支撑点）

1. **纯软的天花板**：饱和、35 岁焦虑、岗位同质化
2. **嵌软的差异化护城河**：硬件 + 软件 + 行业认知 三层壁垒
3. **第一份实习经验怎么复用**：哪些可迁移 / 哪些要重学
4. **大疆嵌软的具体准备**：补哪些短板（C / RTOS / Linux 驱动）
5. **争议回应**：一年内连转两个方向是不是太激进 → 我的判断标准
