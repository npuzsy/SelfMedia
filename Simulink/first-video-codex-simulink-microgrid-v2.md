# 小红书视频脚本 v2：Codex 调用 Simulink + 最小微电网 Demo

版本：v2.0  
目标时长：3-4 分钟  
形式：竖屏 9:16，屏幕录制为主，少量真人/口播可选  
核心目标：把视频从“能力展示”细化成一个可跟拍的教程型内容。

这版视频主要做两件事：

1. 讲清楚 Codex 是怎么调用 Simulink 的。
2. 展示如何用 `simulink-power-electronics` skill 搭一个最简单的微电网模型。

当前可展示 Demo：

- 模型：`/Users/siyu/Workspace/SelfMedia/Demo/Demo_Microgrid_Droop.slx`
- 生成脚本：`/Users/siyu/Workspace/SelfMedia/Demo/build_demo_microgrid.m`
- 验证结果：5 s 仿真通过；3-5 s 均值约为 `Vbus = 786.573 V`，`Pbat1 = 3508.369 W`，`Pbat2 = 1754.185 W`，功率分配比 `Pbat1/Pbat2 = 1.9989`。

## 1. 这条视频的核心表达

不要把这条视频讲成“AI 很厉害”。  
要讲成：

> 我把电力电子建模流程写成了一个 skill，然后让 Codex 按这个流程调用 Simulink，最后生成了一个可以仿真的最小微电网 Demo。

这句话是全片主线。

观众看完应该知道：

- Codex 不是直接“脑补一个模型”，而是通过 MATLAB/Simulink 工具链打开、编辑、仿真模型。
- skill 的作用是给 Codex 加电力电子领域约束：先识别拓扑、再搭结构、再检查、最后验证。
- 最小微电网 Demo 不是复杂工程模型，但已经能展示一个关键逻辑：两组储能通过 droop 控制给 DC bus 供电，并实现接近 2:1 的功率分配。
