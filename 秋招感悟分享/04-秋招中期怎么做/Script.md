# 秋招中期规划

最近也是进入到秋招的中期了，很多小伙伴已经高做了上百个测评，

面了无数场面试，

但是就是还没有心仪的offer到手，

这期视频主播跟大家分享一下我去年这个时候都做了什么，

有哪些可以参考，哪些可以避雷。

# 心态调整

首先是心态上，因为当时已经麻木了，真的填了大几十家线上简历，

做了几十遍北森测评，

已经不想再投递新的公司了，

而且平时还有很多面试和学校的事情，

心态上已经比较懒惰了。

但是这时候基本上第一批拿offer的同学已经开始晒了，

有的人拿的还是非常令人羡慕的，

这时候懒惰和嫉妒交织在一起，

心态就非常脆弱。

但是这时候我建议大家不要放弃，

再坚持一下，

因为很多公司这时候迎来了第一波违约，

急需补充岗位，

这时候一定一定要多刷刷相关帖子，

看是否还有自己行业但是之前没关注过的公司，

主要就是查缺补漏，

主播最满意的两个offer实际上都是10月份才投递的。

其实我个人理解这时候的秋招有一点小春招的意思，

已经开始捡漏了，但是有些朋友懒惰了，就可能把机会让给别人了，

正直双节期间，公司一般也不处理简历，

刷到视频的朋友可以切出去再投俩简历。

# 信息途径

然后就是和大家分享一些主播整个秋招期间获取信息的途径，

首先就是各种常见的，例如牛某客，这个计算机类的偏多，

但我在准备手撕的时候也会去刷刷，

然后就是各种招聘软件，上面能看到目标公司同类公司和一些吐槽帖子，

有的时候一些关键信息或者宝藏公司经常藏在吐槽的帖子里面。

最后就是主播最常用的某红色软件和音乐软件，

这个确实有非常海量的秋招帖子，

甚至去年主播秋招期间由于看的这类帖子多了，

很多有用的信息就自动推荐给我了，

另外也有一些相关行业的直播间，可以进去白嫖听听，

有的时候还会有意想不到的收获，

主播就是在直播间里认识到了未来的同事+校友。

先把信息获取渠道拓宽，就能很大程度上缓解焦虑。
